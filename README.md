# 🖥️ Tatiya Desktop Installer v3.0

**Turn your Android into a Hacking Machine.**
This tool installs a full Graphical User Interface (GUI) on Termux with **one click**. It automatically fixes the "Black Screen" issue on VNC.

## 🔥 Supported Desktops
Choose from 4 powerful environments:
- **[1] XFCE4** (Recommended: Balanced & Stable)
- **[2] LXQt** (Modern & Lightweight)
- **[3] MATE** (Classic Windows Feel)
- **[4] Openbox** (Ultra-Fast for Hackers)

## ⚡ Features
- 🔧 **Auto-Fix:** Generates `xstartup` to prevent black screens.
- 🔊 **Audio:** Installs PulseAudio drivers automatically.
- 🌐 **Browsers:** Ready for Firefox/Chromium installation.

## 🚀 Installation
Copy and paste these commands in Termux:

```bash
pkg update -y && pkg install git python -y
git clone [https://github.com/TATIYA-for-you/Termux-Desktop-Installer-.git](https://github.com/TATIYA-for-you/Termux-Desktop-Installer-.git)
cd Termux-Desktop-Installer-
python install.py

##🎮 How to Connect
​After installation, type vncserver (Set a password).
​Open VNC Viewer App.
​Connect to: 127.0.0.1:5901.
​Enjoy your new Desktop!
